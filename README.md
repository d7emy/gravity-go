# gravity-go

**[English](README.en.md)**

> تطبيق Antigravity الصراحة سيء ومسحوب عليه ومحد طايق يستخدم واجهته.. بس ميزته كوتته وموديلاته بلاش وحرام تضيع! سحبنا الـ API حقه من تحت لتحت وشبكناه بـ OpenCode عشان تكمل شغلك بمحررك اللي تحبه وبدون ما تدفع قرش إضافي.

موديلات Antigravity الداخلية صارت شغالة عندك كـ API محلي متوافق تماماً مع أنثروبيك (Anthropic) وأوبن إي آي (OpenAI). السيرفس خفيف ومكتوب بـ Go ويجيك في **ملف تنفيذي واحد (static binary)** — لا نود، لا وجع راس CDN، ولا ملفات جانبية تقروشك.

## النكبة اللي تصير دايم

دافع دم قلبك باشتراك OpenCode، وفجأة بنص جلسة برمجة طويلة يجيك الرد **مرفوض بوجهك على طول** (صارت بجلسة حقيقية استهلكت 669 ألف توكن!)، أو فجأة تخبط بسقف الـ **100 أداة**، أو يوقف عليك الشغل كله فجأة بخطأ **429** وباقي لك كم ملف وتخلّص، والعداد يحسب وأنت متنّح في شاشة `retry-after`.

بدال ما تبتلش بتطبيق Antigravity وتجربته التعبانة، وجّه OpenCode على الرابط `http://127.0.0.1:8964` واستهلك **كوتة Antigravity الأسبوعية** على الجاهز — Gemini + Claude شغالين معك بنفس اللوب حق الـ agent. وإذا صفّر حساب قوقل الأول وتعب، الطلب **بينقل للحساب الثاني بسكات وتلقائيًا**. يجيك الرد كامل ومضبوط، ولا بتشم ريحة الإيرور.

## ليش مستخدمي OpenCode بيعشقونه؟

* **البروتوكولين مدعومة:** مسار `POST /v1/messages` (حق Anthropic) ومسار `POST /v1/chat/completions` (حق OpenAI) — مع الـ streaming، استدعاء الأدوات، الصور، وبلوكات التفكير (thinking blocks).
* **مصمم للجلسات الثقيلة:** يتحمل معك لحد 100,000 رسالة و 10,000 أداة بكل طلب.
* **ما يموت إذا خلصت الكوتة:** حساب واحد يخدمك لين يصكك بـ `429 quota_exhausted` — بعدها يريّح الحساب، ينزله للاحتياط، ويكرر المحاولة بتلقائية بحساب ثاني، وكل هذا محفوظ حتى لو طفيت وشغلت السيرفر.
* **ملف واحد بس:** لوحة تحكم مدمجة جوا الملف (`go:embed`)، خفيفة وشغالة أوفلاين بدون نت.

أسرع طريقة ربط (من [توثيق OpenCode للـ providers](https://opencode.ai/docs/providers/) بأسلوب `baseURL`):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "anthropic": {
      "options": { "baseURL": "http://127.0.0.1:8964" }
    }
  }
}
```

أو تخليه مزود محلي مخصص (نفس طريقة Ollama):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "gravity-go": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "gravity-go (local)",
      "options": { "baseURL": "http://127.0.0.1:8964/v1" },
      "models": {
        "gemini-3.8-flash-high": { "name": "Gemini 3.8 Flash (High)" }
      }
    }
  }
}
```

حط أي مفتاح وهمي يعجبك (`ANTHROPIC_API_KEY=dummy`) — السيرفر شغال بروكسي محلي (loopback)، فما يحتاج مفتاح حقيقي أصلًا.

## كيف تشغله؟

ما يطلب منك إلا **Go 1.25.7+** فقط.

```bash
git clone https://github.com/<you>/gravity-go.git
cd gravity-go
go run .                    # كأنك مسوي start بالضبط
go build -o gravity-go.exe .
```

يشتغل على البورت **8964**، والداشبورد تلقاها على `http://localhost:8964/quota`

```bash
gravity-go start [-p PORT] [-v]  # البورت الافتراضي 8964
gravity-go login                 # ضيف حساب قوقل عبر OAuth
gravity-go accounts              # يعرض لك لستة الحسابات
gravity-go logout-ide            # يسجل خروج المحرر ويصفر الجلسة
gravity-go version               # يطبع لك رقم الإصدار
```

## تسجيل الدخول: طريقتين بالترتيب

1. **عبر OAuth** — شغل `gravity-go login` ← وافق في صفحة قوقل ← التوكنات تنحفظ في `~/.gravity-go/auth.json`. تقدر تضيف أكثر من حساب وبيبدل بينهم تلقائيًا.
2. **عبر المحرر المحلي (IDE)** — ما عندك جلسة OAuth؟ بيقرا التوكن مباشرة من ملف `state.vscdb` حق Antigravity (قراءة فقط بدون تعديل).

البيانات تتخزن في `~/.gravity-go`؛ ولو كان عندك مجلد قديم باسم `~/.anti-api` بيعتمد عليه عادي إذا المجلد الجديد مو موجود. تقدر تغير المسار يدويًا بمتغير `GRAVITY_DATA_DIR`.

## وش الموديلات المتاحة؟

| الموديل | تفاصيله |
| --- | --- |
| `gemini-3.8-flash-high` | أحدث فلاش، وهو الخيار الأساسي والافتراضي |
| `gemini-3.7-flash-high` | الفلاش اللي قبله |
| `gemini-3.1-pro-high` | الأقوى فيهم ومخصص لجلسات التفكير الطويلة والعميقة |
| `claude-opus-4-6-thinking` | كوتة أسبوعية مستقلة لحالها |

مسار `GET /v1/models` يشتغل بنظام القائمة البيضاء (whitelist) — تقدر تنادي موديلات ثانية بأسمائها ويسوي لها تحويل داخلي (يحول `-high` إلى المعرفات الفعلية `-tiered`).

* **Anthropic:** مسارات `POST /v1/messages` (مع `/v1beta/messages` و `/messages`).
* **OpenAI:** مسار `POST /v1/chat/completions` — مع خيارات `reasoning_effort` و `stream_options.include_usage`.
* **البحث:** مسار `GET|POST /search` — يعطيك إجابات موثقة مع مصادرها.
* **الداشبورد:** مسارات `/quota`, `/quota/json`, `/usage`, `/settings`, `/logs`, `/auth/*`, `/accounts/*` — خفيفة وبدون رهن لأي CDN وتشتغل أوفلاين.

التوثيق الكامل: [API.md](API.md)؛ والعقد التفصيلي لكل مسار: [LOCALAPI.md](LOCALAPI.md).

## التبديل والتوقيف المؤقت

* الحسابات تخدمك **واحد ورا الثاني حسب ترتيب حفظها** — ومتعمدين ما نعتمد على كشف نسبة الكوتة (لأن نسب الكاش تلعب عليك وماتعكس الواقع مع كل ريكويست).
* تقدر توقف حساب مؤقتًا من الداشبورد أو بأمر `POST /accounts/{id}/enabled` — يحتفظ ببيانات الدخول ويشيل فترة الانتظار (cooldown) أول ما ترجعه يشتغل.
* وقفت **كل الحسابات**؟ بيعطيك خطأ صريح `503 All accounts are paused` بدال ما يروح يشتغل من وراك ويصرف بدون علمك.

## الإعدادات ومتغيرات البيئة

| المتغير | القيمة الافتراضية | وش يسوي؟ |
| --- | --- | --- |
| `GRAVITY_DATA_DIR` | `~/.gravity-go` | مسار البيانات والإعدادات |
| `GRAVITY_HOST` / `GRAVITY_PORT` | `127.0.0.1` / `8964` | ربط الهوست والبورت (تمرير `-p` يلغي هذا) |
| `GRAVITY_ACCOUNT_CONCURRENCY` | `1` | كم ريكويست شغال بنفس اللحظة للحساب الواحد (من 1 إلى 8) |
| `GRAVITY_ACCOUNT_INTERVAL_MS` | `1000` | أقل فاصل زمني بين طلبات الحساب الواحد (بالميلي ثانية) |
| `GRAVITY_MIN_REQUEST_INTERVAL_MS` | `250` | الفاصل الزمني العام للطلبات |
| `GRAVITY_SEARCH_TOKEN` | غير محدد | يطلب توكن حماية لمسار `/search` |
| `GRAVITY_NO_OPEN` / `GRAVITY_OAUTH_NO_OPEN` | غير محدد | تحط `1` عشان يمنع فتح المتصفح تلقائيًا |
| `GRAVITY_INSECURE_TLS` | غير محدد | تحط `1` لتعطيل فحص TLS (بروكسيات الشركات بس) |
| `GRAVITY_JITTER` | مفعّل (enabled) | تحط `0` عشان تلغي العشوائية وتخلي المسار ثابت |

> ⚠️ انتبه: إذا حطيت `GRAVITY_HOST=0.0.0.0` بيخليه يستمع على *كل المنافذ* — يعني صار بروكسي مفتوح بدون باسوورد وحاط فيه بيانات قوقل حقتك على الشبكة المحلية كلها. راجع متغيراتك زين إلا لو ودك تعزم زباين الكافيه على كوتتك بدون ما تدري.

## عشان نكون صريحين معك (تجارب حقيقية)

* **إعدادات أخذ العينات (Sampling params) ما تشتغل:** خيارات زي `temperature`/`top_p`/`top_k` توصل للسيرفر الأصلي ويسحب عليها تمامًا. جربنا حطينا `temperature: 0` ورجع لنا أربع جمل مختلفة!
* **سبب التوقف `stop_reason` يصرّف لك أحيانًا:** إذا حسيت النص انقطع، قارن يدويًا بين `usage.output_tokens` و `max_tokens`.
* **الصور لازم تكون بصيغة Base64:** لو أرسلت رابط صورة (URL) بيتحول لملاحظة نصية واضحة `[image omitted: …]` بدال ما يقعد الموديل يهلوس ويخترع لك وصف من كيسه.
* **حسبة التكلفة بالدولار تراها شكلية:** نظام الحسابات كوتة أسبوعية مو دفع بالتوكن — يعني كل أرقام المبالغ هذي استعراضية عشان تتخيل الحجم بس.

## أشياء استبعدناها عن قصد

البرنامج مسوّى لسحب خدمات Antigravity واستغلالها فقط. لا تنتظر منه توجيه شبكات متقدم، ولا أنفاق وتخريم (tunnels - جيب ngrok حقك معك)، ولا تحديث تلقائي، ولا embeddings — أي مسار مو مدعوم بيصكك بـ `501` صريح بدون لف ودوران.
